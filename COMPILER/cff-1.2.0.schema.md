# Citation File Format 1.2.0 schema

`cff-1.2.0.schema.json` is the official Citation File Format 1.2.0 JSON
schema, vendored so tests do not depend on network access.

Source:
`https://github.com/citation-file-format/citation-file-format/blob/0c5b4aa07071490eaf261775ce96ccdd13a6e2d5/schema.json`

The upstream Citation File Format repository distributes the schema under
the Apache License 2.0.
